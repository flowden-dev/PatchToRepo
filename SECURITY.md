# Security

For a path traversal, unexpected write or similar defect, use the repository's
private vulnerability reporting feature if enabled. Otherwise contact the
maintainer privately. Do not publish exploit patches containing private source
or credentials. For ordinary bugs, use the issue template.

Include the application/Git/OS versions, a minimal disposable repository and a
small patch. Describe whether a preview, check or Apply operation was involved.
See [safety and limits](docs/safety.md) for the supported input boundary.
